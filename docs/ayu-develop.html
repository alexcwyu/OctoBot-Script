Design decisions

Decision Rationale Tradeoff Evidence
Inject script callback into host trading mode. Reuse existing OctoBot execution/context and historical replay machinery. Class-level _import_scripts replacement shares mutable registration across same-process runs. _register_script (L119)
Require run storage for plots. Reports load historical/chart data through run database identifiers. Storage-disabled backtests cannot plot through this API. BacktestResult.plot (L38)

Strengths and limits

Strengths

  • Historical file matching avoids collecting the same available range again. historical_data (L54)

Limitations

  • Callback exceptions are logged and swallowed by combined callback; callers should inspect logs and report rather than assume every candle succeeded. _build_script (L91)

Validation scope

The linked validation and command records preserve actual historical runs and user-authorized exclusions. This source/document review does not rerun application tests, establish live trading readiness or rank benchmark performance. Current data, credential and runtime prerequisites remain material.
